34 of my Claude Code skills had never been used. Not once.

I built a few dozen Claude Code skills... and never used them again.

They sounded great at the time.

But I forgot about them.

Later I discovered, every installed skill adds to the system prompt on every turn.

One analytics plugin was contributing 164 skills and about 30,000 tokens a turn.

So I built a routine:

↳ Ask Claude what skills to create, based on how I actually work. Say yes to a few, no to most.
↳ Run /plugin stats now and then. Anything with zero invocations gets disabled.
↳ Run /insights once a week. It suggests the next skill worth creating from what went wrong.
↳ Read every new skill file before keeping it. It is markdown, so that takes two minutes.

The skills I actually use every week: PRD, PRD critic, projects, triage, picker, log, PRs.
