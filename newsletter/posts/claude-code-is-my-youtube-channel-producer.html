Claude Code is my YouTube channel producer

Claude Code is my YouTube channel producer.

(Well, almost.)

I have 861 videos on the channel.

Most were published years ago.

Old titles. Boilerplate descriptions. Dead links everywhere.

Fixing that manually would take weeks. So I connected Claude Code to the YouTube API instead.

Here's what it did:

↳ Audited every video against 12 months of real search queries
↳ Rewrote 23 titles and descriptions based on what people actually type
↳ Sorted every public video into the right playlist
↳ Found 100+ videos with dead links and queued the fixes
↳ Generated thumbnails with my face, using an AI persona I trained on 3 headshots
↳ Scheduled three weeks of uploads for 9am US Eastern

Publishing a video now looks like this:

I record and upload. Claude Code pulls the transcript, offers me 3 title options backed by search data, writes the description and chapters, makes the thumbnail, picks the playlist, schedules it.
