Agent skills

Skills and workflows for AI coding agents, taken from my own setup and made generic so they work in any repo.

Each one is a plain Markdown procedure. They ship as Claude Code slash commands, but the same text works as a Cursor rule or a prompt for any capable agent. Every skill here earned its place by catching something real. MIT licensed.

github.com/bryancollins99/agent-skills

Install all of them

git clone https://github.com/bryancollins99/agent-skills.git
cp agent-skills/skills/*.md ~/.claude/commands/

Git hygiene

  • /pre-commit-review

    A second pair of eyes before you commit.

    Read and install

  • /merge-conflict-walkthrough

    Reads both sides of every conflicted file and proposes a resolution with its reasoning.

    Read and install

  • /rebase-plan

    Drafts the pick / squash / reword todo list for git rebase -i before you open the editor.

    Read and install

  • /branch-cleanup

    Lists merged and stale local branches, deletes the safe ones, flags the rest.

    Read and install

Wiring and environment

  • /wiring

    Compares the secrets and env vars your code declares against what is actually set, on both GitHub Actions and Netlify.

    Read and install

Issues to shipped code

  • /log-issue

    Files the bug you just spotted as a GitHub issue on the current repo and then stops.

    Read and install

  • /fix-cluster

    Fixes a set of related issues as one pull request.

    Read and install

  • /best-of-both

    Compares two agents' builds of the same spec section by section, picks a base, and writes one brief that folds the other build's best ideas into it.

    Read and install

Keeping automation honest

  • /cron-staleness

    Audits every scheduled GitHub Actions workflow for silent death: not the runs that failed, the runs that should have happened and did not.

    Read and install

Thinking and communicating

  • /decide

    Takes the "Open questions" section that every plan grows and forces each item to a lock, one question at a time, then writes the answers back into the doc.

    Read and install

  • /explain

    Retells whatever you just built or found as plain-language use cases from the point of view of the person who benefits, not the person who built it.

    Read and install

  • /notes-to-ideas

    Mines a folder of your own notes for things worth writing, weighted to recent material but forced to resurface older notes that connect to a current thread.

    Read and install

  • /remember

    Captures what the session taught into a file-based memory store, and separately flags memories whose commitment date has passed.

    Read and install
