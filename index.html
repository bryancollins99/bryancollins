    Agent skills

    All 13 skills

    The workflows I run Claude Code with every day, published as plain Markdown. MIT licensed, on GitHub.

    • /pre-commit-review A second pair of eyes before you commit.
    • /merge-conflict-walkthrough Reads both sides of every conflicted file and proposes a resolution with its reasoning.
    • /rebase-plan Drafts the pick / squash / reword todo list for git rebase -i before you open the editor.
    • /branch-cleanup Lists merged and stale local branches, deletes the safe ones, flags the rest.
    • /wiring Compares the secrets and env vars your code declares against what is actually set, on both GitHub Actions and Netlify.
    • /log-issue Files the bug you just spotted as a GitHub issue on the current repo and then stops.
